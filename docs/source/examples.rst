Examples & Patterns
===================

WKafka provides 14 production-ready example scripts in ``examples/``:

1. **01_basic**: Basic JSON messaging.
2. **02_advanced**: Dynamic consumer groups, headers, and SASL contexts.
3. **03_multimedia**: Real-time image and video frame streaming.
4. **04_security_sasl**: SCRAM-SHA-512 authentication.
5. **05_patterns**: Topic chaining and pipeline forwarding.
6. **06_images**: Image compression with JPEG quality control.
7. **07_files**: Document and raw binary file streaming.
8. **08_manual_commit**: Manual offset commit control.
9. **09_retries_and_dlq**: Automatic backoff retries and Dead Letter Queue routing.
10. **10_multi_topic_regex**: Pattern topic subscription.
11. **11_async_handlers**: Native async/await callback triggers.
12. **12_pydantic_validation**: Strongly-typed model validation.
13. **13_partition_scale**: Automatic topic partition scaling.
14. **14_interactive_producer**: Real-time interactive message dispatcher.
