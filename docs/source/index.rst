Welcome to WKafka's Documentation!
===================================

**WKafka** is a professional, decorator-based Kafka wrapper suite for Python with built-in support for JSON, multimedia (images/video frames), file streaming, Pydantic validation, and automatic partition scaling.

🛠️ Tecnologías y Librerías Relevantes
======================================

- **Python (>=3.9, <3.15)**: Core programming language.
- **kafka-python-ng**: Asynchronous high-throughput Kafka client core.
- **OpenCV & Pillow**: Real-time image array serialization and matrix decoding.
- **Pydantic (v2)**: Strongly-typed schema validation and deserialization.
- **PyYAML**: YAML configuration serialization.
- **python-snappy**: High-throughput CPU-efficient streaming compression.
- **Pytest & Pytest-Cov**: Automated unit testing and 96% guaranteed coverage.
