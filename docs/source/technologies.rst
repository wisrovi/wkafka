🛠️ Tecnologías y Librerías Relevantes
======================================

The WKafka ecosystem incorporates the following core technologies:

* **Python (>=3.9, <3.15)**: Multi-version compatibility.
* **kafka-python-ng**: Core low-latency broker protocol library.
* **OpenCV (cv2)**: Matrix encoding/decoding for real-time vision pipelines.
* **Pillow (PIL)**: Image object manipulation.
* **Pydantic (v2)**: Data validation and schema enforcement.
* **python-snappy & cramjam**: High-speed compression algorithm.
* **Pytest & Pytest-Cov**: Automated unit testing with 96% coverage guarantee.
* **Sphinx & ReadTheDocs Theme**: Automated documentation generation for GitHub Pages.
