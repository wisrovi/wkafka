Pure Python Kafka

Define your callback triggers, set your serialization format, and let wkafka handle orchestration, threading, and error recovery.

  • Automatic JSON, YAML, Image, File, and Pydantic serialization
  • Native async/await callback support for high concurrency
  • Manual offset commit control and headers metadata tracing
from wkafka import WKafka
import cv2

# Instantiate client
kafka = WKafka(bootstrap_servers="localhost:29092")

# Register vision stream consumer
@kafka.consumer(topic="video_frames", format="image")
def on_frame(msg):
    frame = msg.value # NumPy ndarray (BGR)
    print(f"Frame shape: {frame.shape}")

# Run consumer pool with auto-partition scaling
if __name__ == "__main__":
    kafka.run_consumers(block=True, partition_scale=True)
